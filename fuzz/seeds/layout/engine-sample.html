Fortress mode turns HTML and CSS into pixels on the CPU, with fonts compiled into the browser, so every computer produces the same image.

This promotional banner is hidden with display: none.

Hollow is a privacy browser written in Rust. Pages are parsed with html5ever, styled by a small cascade, laid out in blocks and lines, shaped with HarfRust and rasterized by tiny-skia. Long words such as Donaudampfschifffahrtsgesellschaftskapitän still wrap, and Download buttons keep their colors.

Note: scripts are dropped while parsing — there is nothing to run them with.

What works

  • Block and inline layout with margin collapsing
  • Lists, including nested ones:
    1. Ordered items
    2. With underlined and struck text
  • Tables with automatic column widths
